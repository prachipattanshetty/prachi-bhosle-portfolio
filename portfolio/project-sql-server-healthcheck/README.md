# SQL Server Health Check & Diagnostics Framework

## Overview
A framework for proactive SQL Server monitoring and diagnostics.

## Components
- CPU, memory, IO, and wait stats monitoring
- Blocking and deadlock detection
- Index fragmentation and statistics reports
- Error log scanning automation

## Impact
- Reduced production incidents
- Improved system stability
- Enabled proactive performance management

## Tools Used
SQL Server • DMVs • PowerShell • T-SQL
