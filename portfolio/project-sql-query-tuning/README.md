
# SQL Query Optimization & Index Tuning

## Overview
This project showcases my approach to improving SQL Server query performance for reporting pipelines.

## Problem
Slow-running queries were causing timeouts and delaying daily reporting.

## Actions
- Reviewed execution plans
- Identified missing/unused indexes
- Rewrote queries using CTEs and window functions
- Implemented index maintenance strategy

## Results
- Improved query performance by 60–80%
- Reduced blocking and deadlocks
- Stabilized reporting pipelines

## Tools Used
SQL Server • T-SQL • Execution Plans
