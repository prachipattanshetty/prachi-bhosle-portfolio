
# Sales Performance Dashboard (Power BI)

## Overview
A mobile-friendly dashboard designed for sales reps to access insights during retailer visits.

## Features
- Sales trends and YoY comparison
- SKU-level performance
- Region and brand drill-downs
- Mobile-optimized layout

## Tools Used
Power BI • SQL

## Impact
- Improved field decision-making
- Increased dashboard adoption
- Reduced manual reporting time
